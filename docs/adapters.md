# 来源适配

首版使用 `src/cloudsub/sources.py` 中的两个来源，不需要插件注册器。

| 来源 | 接口 | 使用方式 |
| --- | --- | --- |
| `HttpSource` | `download(path, target)` | `path` 必须为空；下载配置中的完整 URL |
| `WebDAVSource` | `files(folder, recursive)`、`download(path, target)`、`upload(path, content)` | 路径相对于配置的 WebDAV 端点 |

两个来源都支持上下文管理以关闭连接。`RemoteFile` 提供相对路径与可缺省大小；CLI 决定媒体筛选、本地任务 ID、识别、翻译与可选上传。远端文件名不决定本地文件路径。

## 先按协议接入

OpenList 或其他网盘若已提供 WebDAV，只需填写其完整端点与 Basic Auth 环境变量，无需增加网盘专用代码。端点的 `/dav/` 等基路径必须保留。HTTP 直链可包含签名 query，但不具备列目录和写回能力，不应伪装成 WebDAV。

WebDAV 路径由调用方传入解码后的字符串，由来源统一编码；XML 返回的绝对或相对 `href` 需验证仍在初始来源与配置根目录内。不要通过字符串拼接把未校验的远端路径交给本地文件系统。

## 新增来源的最小要求

只有协议无法满足实际服务时才增加专用来源，并在 CLI 选择处接入。用人工响应测试必要行为：

- 中文、空格、百分号与 `#` 的正确编码，基路径保留，目录自身排除，递归去重与条目上限。
- 外部来源、路径穿越、无效大小、危险 XML、超大响应和下载中断拒绝；异常不暴露原始 URL 或响应。
- 初始来源才接收凭据；跨域、跨端口重定向不携带认证或 Cookie；HTTPS 不降级。
- 下载不覆盖既有目标，失败清理局部文件；上传只接受字幕，条件创建后回读校验，失败保留本地字幕。

实际网关可能不支持写入、忽略条件头或使用不同重定向行为。先使用单独的空测试目录验证，再声明该服务的兼容范围。不要把协议单元测试结果写成“兼容所有网盘”。

首版不包含网盘原生登录、Cookie 导入、验证码处理、DRM、断点续传或自动重试。遇到这些需求时先明确授权、凭据保存方式与可测试的最小范围。

## 翻译接口边界

翻译接口与媒体来源分开，识别仍在本机。`provider` 选择 `ollama`、`openai`、`anthropic` 或 `gemini`；后两种使用原生协议，不能只替换 OpenAI 请求地址。

`deepseek`、`qwen`、`doubao`、`zhipu`、`kimi`、`hunyuan`、`qianfan`、`minimax` 是 OpenAI 兼容协议的预设，由配置提供默认基地址，不各自维护重复的请求实现。显式 `url` 可覆盖地区或账户端点；模型没有预设，必须由使用者从服务商控制台确认。

| 协议 | 基地址后的请求路径 | 认证与输出约定 |
| --- | --- | --- |
| OpenAI 兼容（含中国 API 预设） | `/chat/completions` | Bearer 请求头；默认 JSON 输出设置 |
| Anthropic 原生 | `/messages` | `x-api-key` 请求头；严格 JSON 提示后校验 |
| Gemini 原生 | `/models/{model}:generateContent` | `x-goog-api-key` 请求头；JSON mode |

Gemini 模型配置仅接受模型名，程序构造路径。所有翻译结果都需要验证结构、条目数量和类型，错误响应不能暴露密钥、请求正文或字幕；格式不满足时保留本地原文，不把错误内容写成字幕。

OpenAI 兼容模型不接受 `response_format` 时，可用 `json_mode = false` 省略该请求参数；这不放宽返回 JSON、条目数量与类型的校验。不要为绕过单个模型的限制而改成接受任意文本。区域端点、豆包推理接入点 ID 和混元新旧平台的权限差异由配置与文档说明，不放进网盘来源代码。

远端翻译要求显式开启 `allow_remote`、HTTPS 与 `api_key_env` 指向的密钥，默认仍限本机回环 IP。翻译不跟随重定向，不读取代理环境变量，不把密钥写进 URL；仅发送字幕正文，不能把媒体文件或来源凭据带入翻译请求。

新增或修改协议时，测试请求方法/路径/头部/JSON 结构、受限 URL、缺失密钥、远端默认禁用、重定向拒绝与异常脱敏。协议模拟测试不能代替真实服务验证，也不证明模型格式兼容、费用或保留策略。实际计费调用需由使用者单独选择。

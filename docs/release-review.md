# 首版发布审阅

审阅范围：单用户命令行的数据流、HTTP/WebDAV 输入、缓存与写回、本地识别、翻译 API、发布文件及提交身份。审阅后已修复以下实际问题，并添加回归测试。

1. **不同账号可能共用字幕缓存。** 相同端点与文件路径曾生成相同任务 ID，可能把一个账号的字幕复用于另一个账号。任务 ID 现包含账号维度，测试验证两个账号独立识别与保存；不把密码或密码摘要纳入公开任务 ID。
2. **部分合法 WebDAV 目录被漏扫。** 服务器可把文件大小和目录类型放在不同的成功 `propstat` 中。解析器现汇总全部成功属性，测试验证子目录仍会递归扫描。
3. **离线识别存在分词器下载回退。** 依赖在模型缺少 `tokenizer.json` 时可能联网。离线模式现只解析已有缓存，并在初始化前验证分词器文件，测试验证缺失时不会进入回退。

发布文件按白名单检查，排除本机配置、环境变量文件、模型、媒体、字幕、日志、数据库、虚拟环境和测试运行产物。真实账号、路径及凭据不属于公开源码。发布检查不能替代人工审阅，也不保证 GitHub 账号本身匿名。

已执行本地自动测试、依赖检查、发布隐私扫描与构建检查。真实合成语音已验证本地识别，翻译协议使用模拟服务验证，不调用收费 API。

首版仍有明确限制：长音频整段解码可能占用较多内存；翻译后续批次失败重跑可能重复计费；忽略条件写入头的 WebDAV 服务器无法保证远端防覆盖。这些限制已在 README 中说明。

真实私人网盘、收费 API、CUDA 和其他操作系统需分别验证；GitHub Actions 的跨平台结果以仓库实际运行记录为准。
